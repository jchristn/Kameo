# Kameo

Read [AGENTS.md](AGENTS.md) for repository conventions, requirements applicability, credential boundaries, and the test workflow. Keep namespace-first C# blocks, explicit types (no `var`), no partial types, `_PascalCase` fields, documented public APIs, cancellation-aware async methods, one type per file, and no tuples or em dashes.

The product is a compact local credential manager. Never use real credentials in tests or change version numbers without explicit instructions.
